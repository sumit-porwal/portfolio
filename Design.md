# 🎨 **3. DESIGN SYSTEM INSTRUCTIONS**

## **3.1 Colors**

* **#000000** — Background
* **#FFFFFF** — Text
* **#0AFF9D or #00E0FF** — Accent neon
* Greys for UI surfaces: #0D0D0D / #1A1A1A / #2C2C2C

## **3.2 Typography**

* Headline font: **Satoshi / Inter / Space Grotesk**
* Body font: **Inter / IBM Plex Sans**
* Hero heading weight: 700
* Body weight: 400–500
* Use large type with lots of breathing room

## **3.3 Components**

* Buttons: pill-shape or subtle rounded
* Cards: soft shadows, minimal borders
* Icons: lucide-react style (thin, modern)

# ⚡ **4. COPYWRITING STYLE GUIDE (VERY IMPORTANT)**

Your agent must follow these rules:

### **Do:**

* Short sentences
* Clear value-first writing
* Strong verbs
* No jargon unless necessary
* Use “I build…”, “I help…”, “I solve…” phrasing

### **Avoid:**

* “Hello my name is…”
* Long paragraphs
* Overly emotional stories
* Being generic like “I am passionate about coding…”
